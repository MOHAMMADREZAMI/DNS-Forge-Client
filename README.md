# DNS Forge

**DNS Forge** is a Windows DNS management utility designed to simplify DNS configuration and connectivity testing.

## Features

- **DNS Switching:** Quickly change your system's DNS configuration.
- **DNS Benchmark:** Test connectivity to websites using different DNS configurations.
- **DNS Presets:** Use predefined DNS configurations.
- **Connectivity Testing:** Evaluate connectivity across multiple destinations.
- **Simple Interface:** Easy-to-use Windows interface.
